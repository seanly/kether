# 0007 授权

**里程碑** M3 · **依赖** 0002

## 目标

所有者能给另一个 Agent ID 签发授权，服务方能验证这份授权是否允许本次调用。

## 范围

- `auth`：`Grant` 的编码、签名域 `kether/grant/v1`、`node.Grant`
- 校验规则见 [design.md](../design.md) 访问控制一节
- 第一版撤销水位恒为 0，过期靠 `not_after`

本 issue 不把授权放进网络调用。0009 在 `Invoke` 里调用这里的校验函数。

## 实现要点

`max_calls` 在单个进程内存里递减。`0` 表示不限次数。进程重启后计数重新开始，测试要覆盖这一行为，避免以后被当成持久化计数。

时钟偏差 120 秒。`grantee` 必须等于调用方公钥。类型必须落在授权的 `types` 里。

## 验收标准

- [x] 签发的授权能通过校验
- [x] 改字段、过期、grantee 不匹配、类型不在范围内都失败
- [x] `max_calls = 2` 时第三次校验失败
- [x] 新进程上同一授权的次数计数从满额重新开始
- [x] 签名材料里不包含私钥

## 完成情况

`auth` 测试覆盖签发、改字段、过期、grantee 不匹配、类型不在范围内，以及 `max_calls = 2` 时第三次失败。次数只记在进程内的 `Checker`，新建 Checker 从满额重新计数。签名材料是授权正文，不含私钥。
