# 0009 调用状态机与宿主处理函数

**里程碑** M3 · **依赖** 0006, 0007, 0008

## 目标

一次 `Invoke` 走完授权、nonce、支付和处理函数，调用方拿到 `Result` 或稳定错误码。

## 范围

- 帧：`Invoke`、`PayChallenge`、`PayProof`、`Result`、`Error`
- 服务方顺序见 [design.md](../design.md) 调用规则一节
- `Handle` 只在授权和支付都通过之后执行
- 错误码 `1` 到 `8`

## 实现要点

nonce 缓存 `(caller_id, nonce)`，保留到 `sent_at + 10 分钟`。重复 nonce 返回错误，处理函数不会再跑。

`pay` 为空的记录跳过支付。`public` 忽略 grant 字节。`grant_only` 缺少或无效授权时返回错误码 `2`，且不调用 `Handle`。

支付失败返回错误码 `4`，同样不调用 `Handle`。处理函数返回的错误变成错误码 `7`，帧里只有短消息。

测试用 0006 的本地双节点和 0008 的假 Lightning。

## 验收标准

- [x] 公开且标价的调用：挑战、支付、回显 body
- [x] 未支付时 `Handle` 未被调用
- [x] `grant_only` 无授权返回错误码 `2`，`Handle` 未被调用
- [x] 有效授权后调用成功
- [x] 重复 nonce 被拒绝
- [x] 类型不在记录里返回错误码 `5`
- [x] 免费记录（`pay` 为空）不发挑战

## 完成情况

公开标价调用、未支付不进 `Handle`、`grant_only` 错误码 `2`、有效授权后回显、重复 nonce 均有 `node` 测试。类型不在记录里时 `serveInvoke` 返回错误码 `5`。`pay` 为空时跳过挑战，直接进入处理函数。支付失败返回错误码 `4`，处理函数自身的错误返回错误码 `7`。
