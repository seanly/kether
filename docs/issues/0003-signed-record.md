# 0003 签名记录

**里程碑** M1 · **依赖** 0002

## 目标

能签名、编码、解码并验证一条 Agent 记录。本 issue 不发布到 DHT。

## 范围

- `frame` 或 `record` 中的 protobuf：`Record` 与 `PayMethod`，字段见 [design.md](../design.md) 签名记录一节
- 签名输入 `kether/record/v1`
- 发布前校验：类型字符集、类型不超过 8 个、地址不超过 8 个、支付方式不超过 4 个、名称不超过 64 字节、地址非空

## 实现要点

验签失败、公钥与声称的 Agent ID 不一致、`peer_id` 与公钥导出的 Peer ID 不一致、版本不是 1、记录过期（含 120 秒偏差），都返回明确错误。

`seq` 比较由调用方持有「已见序号」。本包提供 `Newer(prev, next)`：`next.seq` 更大才替换；相等则保留先到的一条。

确定性编码后再签名。测试用固定密钥和固定时间，避免依赖网络。

## 验收标准

- [x] 签过名的记录能通过验证，编码往返后字节一致
- [x] 改任一正文字段后签名失败
- [x] 非法类型、空地址、超限列表在签名前被拒绝
- [x] 过期记录验证失败；偏差在 120 秒内的仍接受
- [x] `peer_id` 与公钥不匹配时验证失败
- [x] `seq` 更小的记录不替换已见记录

## 完成情况

`record` 测试覆盖签名往返、篡改正文、非法类型与空地址、过期与 120 秒偏差、`peer_id` 不匹配、较小 `seq` 不替换，以及超过 8 KiB 拒绝编码。测试使用固定密钥，不访问网络。
