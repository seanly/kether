# 0011 链上 Bitcoin 支付通道

**里程碑** M4 · **依赖** 0008, 0009

## 目标

`rail = "bitcoin"` 的调用用本次专属地址收款，确认数到达后才进入处理函数。

## 范围

- `pay/bitcoin`：按 [design.md](../design.md) 链上 Bitcoin 一节实现 `Payee`
- 金额单位 sat
- 默认确认数 1，可配置
- 地址与 `request_hash` 绑定，用过即丢弃

CI 用内存中的假链或 regtest 的桩，不广播到主网或公开测试网。

## 实现要点

`Invoice` 派生新地址并记下期望金额。`Verify` 在确认数不足时返回未完成，调用状态机继续等待直到挑战过期。金额不足或地址不符返回错误码 `4`。

同一地址的第二笔证明无效。

## 验收标准

- [x] 确认数足够且金额足够时 `Verify` 通过，`Handle` 被调用
- [x] 确认数不足时不调用 `Handle`
- [x] 金额不足时返回错误码 `4`
- [x] 同一地址不能证明第二次调用
- [x] 测试不访问公开比特币网络

## 完成情况

`pay.TestBitcoinConfirmations` 覆盖确认数不足、金额不足和同一地址的第二次证明。`node.TestBitcoinGate` 在未确认时不调用 `Handle`，确认且金额足够后回显。金额或地址不符时 `Verify` 失败，调用路径返回错误码 `4`。测试使用 `MemChain`，不访问公开比特币网络。
