# 0012 公网可达性：AutoNAT、中继与打洞

**里程碑** M5 · **依赖** 0004、0006

## 目标

一台或多台公网节点作为种子、AutoNAT 回拨方和 circuit v2 中继。NAT 后面的节点只拨这些种子入网，把经中继转发的地址签进 DHT，使另一台 NAT 节点能够拨通并完成握手。

行为以 [design.md](../design.md) 的「公网可达性」为准。本 issue 不新定义记录字段或签名域。

## 范围

- `Config.Reachability`：`auto`、`public`、`private`。`kether` 根包导出这三个值
- `public`：`ForceReachabilityPublic`、`EnableRelayService`、`EnableNATService`
- `auto` 且种子非空，以及 `private`：`EnableAutoNATv2`、`EnableHolePunching`、`EnableAutoRelayWithStaticRelays`
- 静态中继来自 `Seeds`。预约数 `min(种子数, 2)`
- 地址过滤、地址或可达性变化时重新签名发布
- `cmd/kagent`：`serve --public`、`serve --seed`、`ask --id`；`--announce` 未带 `/p2p/` 时补上本机 Peer ID；已发布地址集合变化时再打印 `addr` 行
- 文档：[kagent.md](../kagent.md)

不实现 UPnP，不在 DHT 里发现中继，不把已握手的流迁到打洞后的连接。

## 实现要点

`Start` 按可达性组装 `libp2p.New` 的选项。`private` 使用 `ForceReachabilityPrivate`。预约失败不让 `Start` 失败；种子一个都拨不通时仍然失败。

发布地址的过滤与重签放在 `signLocked` 和现有刷新协程里。事件订阅先于 `dialSeeds`。`Record.Addrs` 非空时排在过滤结果前面，总数不超过 8。

`Connect` 把非 circuit 地址排在 circuit 前面，逐条拨号。

`kagent serve` 把 `--seed` 传入 `Config.Seeds`。`--public` 设置 `public`。`ask --id` 时 `Resolve` 该 Agent ID，不再 `Search`。

## 验收标准

- [x] 地址过滤丢掉未指定地址；`private` 在有 circuit 地址时丢掉回环和内网地址；操作员地址保留且在前；超过 8 条时截断
- [x] 过滤后的集合不变时，地址事件不递增 `seq`
- [x] 三个本地 Host：A 为 `public`；B、C 为 `private`，静态中继是 A，并且拒绝互相直连。B 的记录出现 `/p2p-circuit` 后，C 能握手，连接的远端地址含 `p2p-circuit`
- [x] 空种子、未设置可达性的节点行为与 0004 相同
- [x] `kagent serve --seed` 把种子传入 `Start`；`--announce` 缺 `/p2p/` 时输出里带有本机 Peer ID

测试使用本地 Host，不访问公网，也不把真实 NAT 上的打洞成功列为验收。

## 完成情况

`TestChooseAddrs` 覆盖过滤、截断和两条 circuit 上限。`TestUnchangedAddrsDoNotBumpSeq` 在地址集合不变时保持 `seq`。`TestRelayHandshake` 用三个本地 Host 走中继握手；中继的回环地址改写成 `libp2p.internal`，这样 circuit 地址能被 libp2p 当作公网地址，测试进程内再解析回 `127.0.0.1`。`cmd/kagent` 的 `TestServeSeedAndAskID` 与 `TestAnnounceAddsPeerID` 覆盖种子、`--id` 和 Peer ID 补全。
