# 0002 身份：密钥与 Agent ID

**里程碑** M1 · **依赖** 0001

## 目标

一把 secp256k1 密钥能导出 Agent ID 和 libp2p Peer ID，并能做 BIP340 签名与验签。

## 范围

- `id`：生成密钥、从文件加载与保存、x-only 公钥、bech32m ID、Peer ID、签名与验签
- 编码规则见 [design.md](../design.md) 身份一节：HRP `keth`，版本字节 `0x00`，32 字节 x-only 公钥

## 实现要点

保存私钥时权限为 `0600`。加载时若权限宽于所有者读写，返回错误。

ID 与 Peer ID 必须来自同一公钥。版本字节不是 `0x00` 的字符串解析失败。

签名函数接受域分隔符和消息，供记录、授权、握手复用。测试覆盖往返，不把私钥打进失败信息。

## 验收标准

- [x] 随机密钥的 ID 以 `keth1` 开头，再解析回同一个 32 字节公钥
- [x] 篡改 ID 一个字符后校验失败
- [x] 非 `0x00` 版本被拒绝
- [x] BIP340 签名能验过，改一个消息字节后验签失败
- [x] 同一公钥导出的 Peer ID 稳定
- [x] 私钥文件为 `0600`，过宽权限拒绝加载

## 完成情况

`id` 测试覆盖 bech32m 往返、篡改一个字符、非 `0x00` 版本、BIP340 验签，以及 `0600` 与过宽权限。生成和加载时若公钥 Y 为奇数则取反私钥，使 libp2p Peer ID 与 x-only 公钥是同一个点。
